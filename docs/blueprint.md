# **App Name**: MeetingAI

## Core Features:

- Real-time Transcription: Transcribe spoken content during the meeting in real-time.
- AI-Powered Summarization: Generate a concise summary of the meeting, highlighting key decisions and action items using an LLM.
- Action Item Extraction: Automatically identify and list action items discussed during the meeting using a tool.
- Sentiment Analysis: Analyze the sentiment of the meeting to gauge overall tone and identify potential issues.
- Keyword Detection: Identify the primary discussion keywords for indexing and searchability.
- Meeting Recording: Record the meeting audio for future reference.
- User Interface: Display meeting transcript, summary, action items and other extracted data in clean, Google Material Design inspired user interface.

## Style Guidelines:

- Primary color: Google Blue (#4285F4) for trust.
- Accent color: Google Red (#EA4335) to highlight energy and action.
- Highlight color: Google Yellow (#FBBC05) to indicate optimism.
- Secondary color: Google Green (#34A853) symbolizing growth.
- Background: Clean white (#FFFFFF) with light grey (#9AA0A6) accents for plenty of whitespace, creating a modern, uncluttered backdrop.
- Body and headline font: 'Inter', a sans-serif, provides a clean and neutral feel for both headlines and body text. Note: currently only Google Fonts are supported.
- Minimalist layout, focusing on easy navigation. UI components with highly rounded corners (full border-radius) to create a friendly, 'bubbly' feel.
- Expressive animations with Motion Physics (spring-based animations) so transitions have a natural bounce at the end.
- Dynamic Width Pills for menu items and buttons that expand smoothly when selected, giving responsive feedback.
- Shape Morphing for decorative elements to move between rounded rectangles and full circles.
